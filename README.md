# 알고리즘 사고력 워크북

조건 판단과 반복문, 순서 추론, 이진 탐색을 연습하는 20문제 워크북입니다.

- [HTML 워크북](workbook.html) - 답안 입력, 자동 저장, 정답·해설 펼치기 기능. HTML 파일을 내려받아 브라우저에서 열어도 사용할 수 있습니다.
- [인쇄용 PDF](algorithm_thinking_workbook.pdf) - A4 9쪽, 풀이 공간과 정답·해설 포함.

문제 구성: 1~6번 조건 판단과 반복문 / 7~13번 등교 순서 추론 / 14~20번 이진 탐색.

# 면접 대비 문제집

- [면접 대비 문제집](interview.html) - 학교이해 2세트 + 기본코딩 3세트, 각 10문항과 모범답안. 2027학년도 전형요강 기준.

## 추가 워크북

- [홈](index.html): 워크북4세트와 면접 자료를 선택합니다. 각 자료에 홈 이동을 제공합니다.
- [2세트](workbook-set2.html): 책 고르기6문제, 발표 순서7문제, 이진 탐색7문제.
- [3세트](workbook-set3.html): 누적 적재6문제, 개발 작업 순서7문제, 이진 탐색7문제.
- 세트마다 독립적으로 답안을 자동 저장합니다. 기존1세트 기록 키와 PDF는 유지합니다. 추가 세트는 인쇄 버튼으로 인쇄/PDF 저장할 수 있습니다.
- 생성: python build_workbook_sets.py. 2·3세트는 자체 제작 연습 문제이며 학교 공식 기출문제라는 의미가 아닙니다.

## 4세트 — 설명회 유형 응용

- [4세트](workbook-set4.html): 순서도 완성과 종료 조건6문제, 어긋난 조건 찾기와 순서 추론7문제, 1기반 의사코드 추적과 오류 설명7문제. 총4세트80문제.
- 사용자가 제공한 설명회 사진의 문제 유형을 분석해 새 상황/숫자/질문으로 자체 제작. 순서도 그림, 정답·해설, 30~60초 구술 풀이 안내 포함. 공식 기출/공식 채점표라는 뜻은 아닙니다.
- 기존1~3세트 문항·기록 키 유지. 4세트는 daeduck-workbook-set4-v1-answer-*로 별도 저장. 홈 및 모든 워크북에4세트 연결.
- 검증: 7팀5040개 순열에서 유일해와 위반 조건/완화 조건 확인, 1기반 이진 탐색의 정상/누락/경계/무한반복/비정렬 사례 및 랜턴 선택 분기 확인. 390/1280px 저장 분리·진행률·정답 펼침·인쇄·홈 이동 검사. 실물 기기와 실제 면접 채점은 미검사.
