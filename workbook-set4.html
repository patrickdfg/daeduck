01

순서도 완성과 종료 조건

조건식·반복·경계값을 순서도와 말로 설명합니다.

자료: 캠프 랜턴 대여 알고리즘

랜턴 8개를 1번부터 차례로 확인합니다. 밝기 300루멘 이상, 사용 시간 6시간 이상, 대여료 4,000원 이하를 모두 만족하는 첫 랜턴을 찾으면 번호와 ‘대여’를 출력하고 즉시 종료합니다. 끝까지 없으면 ‘대여 불가’를 한 번 출력합니다. 목록의 방 번호는 1~8입니다.

번호밝기(루멘)사용 시간(시간)대여료(원)
125083000
235053500
330064000
440084500
545073800
650042500
732093900
833063600

순서도 약속: 타원은 시작·종료, 사각형은 처리, 마름모는 판단입니다. 참·거짓 화살표를 따라가며 말해 보세요.

01

랜턴을 대여할 수 있는 조건식을 AND로 연결하고, 각 비교 기호의 뜻을 설명하세요.

정답 · 해설 보기
밝기 ≥ 300 AND 사용 시간 ≥ 6 AND 대여료 ≤ 4000

‘이상’과 ‘이하’는 기준값과 같은 경우를 포함합니다. 세 조건이 모두 참이어야 대여할 수 있습니다.

02

순서도의 [A]~[D]에 들어갈 조건·처리를 채우고, 반복이 끝나는 두 경우를 설명하세요.

정답 · 해설 보기
[A] 번호 ≤ 8 / [B] 밝기 ≥ 300 AND 사용 시간 ≥ 6 AND 대여료 ≤ 4000 / [C] 번호와 ‘대여’ 출력 / [D] 번호 ← 번호 + 1

조건을 만족하면 C에서 출력 후 종료합니다. 전부 실패하면 D로 번호가 9가 되어 A가 거짓이 되고 ‘대여 불가’ 출력 후 종료합니다.

03

원래 목록으로 실행할 때의 출력과 확인 횟수를 말하고, 1·2·3번을 판단한 근거를 설명하세요.

정답 · 해설 보기
3번 대여 / 3개 확인

1번은 밝기 부족, 2번은 사용 시간 부족입니다. 3번은 300·6·4000으로 경계값을 모두 만족하므로 바로 종료하며 뒤의 후보는 확인하지 않습니다.

04

3번 랜턴의 대여료만 4,001원으로 바꾸면 결과와 확인 횟수는 어떻게 바뀌나요?

정답 · 해설 보기
5번 대여 / 5개 확인

3번과 4번은 대여료 초과입니다. 5번이 다음으로 세 조건을 모두 만족합니다. 이 문항의 변경은 다른 문항에 이어 적용하지 않습니다.

05

새로 시작해 3·5·7번 대여료를 각각 4,001원으로 바꿉니다. [A]를 ‘번호 < 8’로 잘못 쓰면 무엇이 출력되나요? 올바른 결과와 고칠 조건도 말하세요.

정답 · 해설 보기
잘못된 조건: 대여 불가 / 올바른 조건 번호 ≤ 8: 8번 대여

잘못된 반복은 1~7번만 확인하여 마지막 적격 후보를 놓칩니다. 등호를 넣으면 8개를 확인한 뒤 8번을 고릅니다.

06

‘대여 불가’를 매번 B의 거짓 화살표에서 출력하면 어떤 문제가 생기나요? 올바른 출력 위치와, 8개가 모두 실패할 때의 출력 횟수를 설명하세요.

정답 · 해설 보기
뒤에서 성공해도 앞선 실패 메시지가 나오게 됩니다. A가 거짓인 뒤에 두어야 하며, 모두 실패할 때 한 번만 출력합니다.

B가 거짓이라는 것은 현재 랜턴만 조건에 맞지 않는다는 뜻입니다. 모든 후보가 실패했다는 판단은 목록 확인이 끝나야 할 수 있습니다.

02

어긋난 조건 찾기와 순서 추론

각 조건을 독립 검사하고 모순 없이 전체 순서를 구성합니다.

자료: 일곱 팀의 로봇 시연 순서

A~G 일곱 팀이 한 번씩 시연합니다. 동시에 시연하지 않습니다.

  1. B와 E 사이에는 정확히 두 팀이 있다.
  2. D는 E 바로 전에 시연한다.
  3. F는 B보다 나중에 시연한다.
  4. A보다 먼저 시연한 팀은 많아야 두 팀이다.
  5. A가 가장 먼저 시연한 것은 아니다.
  6. C는 F보다 나중에 시연한다.
  7. G는 C 바로 뒤에 시연한다.

어떤 학생은 D → F → B → A → E → C → G라고 추론했습니다. 각 조건을 독립적으로 확인하세요.

07

제시한 D-F-B-A-E-C-G가 어기는 조건 번호를 모두 쓰고, 위치를 근거로 설명하세요.

정답 · 해설 보기
①·②·③·④

① B는 3번째, E는 5번째로 사이에 한 팀뿐입니다. ② D는 1번째여서 E 바로 앞이 아닙니다. ③ F는 B보다 먼저입니다. ④ A는 4번째라 앞에 세 팀이 있습니다. ⑤·⑥·⑦은 맞습니다.

08

조건 ④·⑤만 적용할 때 A의 가능한 순서를 모두 말하세요.

정답 · 해설 보기
2번째 또는 3번째

앞에 많아야 두 팀이므로 1~3번째이며, 가장 먼저는 아니라는 조건으로 1번째를 제외합니다.

09

이 문제에서 ‘사이에 두 팀’과 ‘바로 전에’를 각각 순서 번호의 식으로 표현하세요.

정답 · 해설 보기
|B의 순서 − E의 순서| = 3 / D의 순서 + 1 = E의 순서

사이의 팀 수와 두 순서 번호의 차이는 1만큼 다릅니다. ‘바로 전’은 다른 팀이 끼어들 수 없다는 뜻입니다.

10

모든 조건을 만족하는 시연 순서를 찾고, A·D·E의 순서를 말하세요.

정답 · 해설 보기
B → A → D → E → F → C → G / A 2번째, D 3번째, E 4번째

B와 E 사이의 A·D 두 팀, D-E의 인접, B-F-C-G의 선후 관계, A의 초기 위치를 모두 확인합니다. 가능한 순서는 하나입니다.

11

조건을 모두 적용할 때 E가 B보다 먼저일 수 없다는 것을 설명하세요.

정답 · 해설 보기
E가 먼저라면 D-E 다음 세 칸 뒤에 B가 오고, B 뒤에 F-C-G 세 팀이 더 필요해 7자리를 넘습니다.

D가 있어 E는 가장 빨라도 2번째입니다. B는 가장 빨라도 5번째이고 F·C·G까지 두면 최소 8자리가 필요합니다.

12

④ ‘A보다 먼저 시연한 팀은 많아야 두 팀이다’만 없애면 원래 정답과 다른 유효 순서를 하나 쓰고 검사하세요.

정답 · 해설 보기
B → F → D → E → A → C → G

A의 앞쪽 팀 수 제한만 없애고 A가 첫 번째가 아니라는 조건은 유지합니다. 다른 여섯 조건을 모두 대입해 확인합니다.

13

원래 일곱 조건에 ‘C는 B보다 먼저 시연한다’를 더하면 가능한 순서가 있나요? 모순을 말로 설명하세요.

정답 · 해설 보기
가능한 순서가 없습니다.

원래 조건은 B < F < C를 요구합니다. C < B를 더하면 B < F < C < B라는 순환이 생깁니다.

03

의사코드 추적과 오류 설명

1부터 시작하는 방 번호로 범위·종료·잘못된 수정을 추적합니다.

자료: 1번 방부터 시작하는 이진 탐색

이 세트의 방 번호는 1부터 9까지입니다. 0부터 세는 Python 리스트와 다릅니다. //는 나눈 몫이며 ‘그렇지 않고/그렇지 않으면’은 한 비교에서 하나의 분기만 실행합니다.

방 번호123456789
값61321283547586982
target ← 찾을 값
array ← [6, 13, 21, 28, 35, 47, 58, 69, 82]
start ← 1
end ← 9
반복 (start ≤ end):
    mid ← (start + end) // 2
    만일 array[mid] = target:
        mid 출력 후 종료
    그렇지 않고 array[mid] > target:
        end ← mid - 1
    그렇지 않으면:
        start ← mid + 1
‘없음’ 출력 후 종료

실행 표를 그릴 때 비교 차례 / start / end / mid / array[mid] / 다음 동작을 구분해 보세요.

14

이 알고리즘이 어떻게 찾는 범위를 줄이는지 말하고, 정렬이 필요한 이유를 설명하세요.

정답 · 해설 보기
중간값과 같으면 찾고, 목표보다 크면 왼쪽, 작으면 오른쪽만 남깁니다.

정렬되어 있어야 중간값보다 작은 값이 왼쪽, 큰 값이 오른쪽이라는 근거로 반대쪽을 제외할 수 있습니다.

15

target=58일 때 각 비교의 start·end·mid·값을 쓰고 최종 출력까지 설명하세요.

정답 · 해설 보기
1차 (1,9,5,35) → 2차 (6,9,7,58) → 방 번호 7 출력

35 < 58이므로 start를 6으로 바꿉니다. 다음에 58을 만나 7을 출력하고 종료합니다. 종료한 뒤 ‘없음’을 출력하지 않습니다.

16

target=40일 때 확인하는 방과 범위 변화를 쓰고, ‘없음’의 출력 횟수를 말하세요.

정답 · 해설 보기
5번(35) → 7번(58) → 6번(47) / ‘없음’ 한 번

범위는 (1,9)→(6,9)→(6,6)→(6,5)입니다. start > end가 되어 반복문 뒤의 실패 출력을 한 번 실행합니다.

17

target=82의 방 번호 추적과 비교 횟수를 쓰세요. 이 배열에서 최대 비교 횟수와도 비교하세요.

정답 · 해설 보기
5 → 7 → 8 → 9 / 4번, 이 배열의 최대 비교 횟수도 4번

오른쪽 끝에 도달하는 경로입니다. 9개 방의 탐색 범위가 9→4→2→1로 줄어 최대 네 번 확인합니다.

18

target=6이고 반복 조건만 start < end로 바꾸면 어떻게 되나요? 원래 조건에서의 탐색 경로도 말하세요.

정답 · 해설 보기
잘못된 조건에서는 5→2번만 확인해 ‘없음’을 출력합니다. 원래 조건은 5→2→1번을 확인해 1을 출력합니다.

범위가 (1,1)일 때도 한 방이 남아 있습니다. 등호를 빼면 마지막 후보를 확인하지 못합니다.

19

target=40이고 작은 값일 때 start ← mid로만 바꾸면 어떤 문제가 생기나요? 반복되는 범위를 쓰세요.

정답 · 해설 보기
범위 (5,6)에서 mid=5가 반복되어 끝나지 않습니다.

처음 mid=5 뒤 start=5, mid=7 뒤 end=6입니다. 이후 mid=5의 값 35가 계속 작지만 start가 다시 5여서 범위가 줄지 않습니다. mid+1로 이미 확인한 방을 제외해야 합니다.

20

배열을 [6,69,21,28,35,47,58,13,82]로 바꾸고 원래 코드로 target=13을 찾으면 무엇이 출력되나요? 이유를 설명하세요.

정답 · 해설 보기
5 → 2 → 1번을 확인한 뒤 ‘없음’을 출력합니다. 실제 13은 8번 방에 있습니다.

배열이 정렬되지 않아 중간값 35를 보고 오른쪽을 버리는 판단이 틀립니다. 이진 탐색 전에 정렬해야 하며, 정렬 후 방 번호는 원래 위치와 달라질 수 있습니다.
